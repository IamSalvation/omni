\# Omni



A modern, streaming AI chatbot built from scratch with vanilla HTML/CSS/JS and Node.js.



\## Features



\- Streaming responses (word-by-word)

\- Conversation memory

\- Persists across page reloads (localStorage)

\- Markdown rendering

\- Dark / light theme

\- Mobile responsive

\- Splash screen

\- PWA-ready (add to home screen)

\- Model fallback across multiple Gemini models



\## Tech stack



\- \*\*Frontend:\*\* Vanilla HTML / CSS / JavaScript

\- \*\*Backend:\*\* Node.js + Express

\- \*\*AI:\*\* Google Gemini (Flash-Lite) via streaming SSE

\- \*\*Markdown:\*\* marked.js
